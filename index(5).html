Anthropeum Export Tools

Choose the option that matches your device and browser. You only need to complete the setup once. After each assigned game, export and save your CSV file.

Option 1

Laptop or Desktop — Google Chrome or Microsoft Edge

We have created an extension in Google Chrome and Microsoft Edge that allows you to download enriched quiz results and additional artefact data for use in a later section assignment.

Show setup and export instructions

Installing the Extension

  1. Click Download Desktop Extension ZIP above.
  2. Double-click the ZIP file to unzip it.
  3. Open Google Chrome or Microsoft Edge.
  4. Go to chrome://extensions in Google Chrome or edge://extensions in Microsoft Edge.
  5. Turn on Developer mode:
    • in the upper-right corner in Google Chrome;
    • on the left side in Microsoft Edge.
  6. Click Load unpacked.
  7. Select the unzipped extension folder.
  8. Confirm that the extension appears in the list and is switched on.

Completing and Exporting the Quiz

  1. Open https://anthropeum.com/.
  2. Complete the quiz and view the results.
  3. The Met-recorded data, including geography and date, and the export buttons should appear automatically.
  4. Click Export CSV to download your enriched results.

Make sure you download the CSV file every time you complete the quiz. You will need these files for a later section assignment.

Option 2

iPhone or iPad — Safari

If you are using Safari on an iPhone or iPad, use the Anthropeum Exporter Shortcut instead of the browser extension.

Install Safari Shortcut
Show setup and export instructions

Installing the Shortcut

  1. Click Install Safari Shortcut above.
  2. The Shortcuts app should open and display Anthropeum Exporter.
  3. Tap Add Shortcut.
  4. Confirm that Anthropeum Exporter appears in your Shortcuts app.

You only need to complete this setup once.

Completing and Exporting the Quiz

  1. Open https://anthropeum.com/ in Safari.
  2. Complete the quiz and remain on the page showing your results.
  3. Tap Safari’s Share button.
  4. Scroll through the Share Sheet and tap Anthropeum Exporter.
  5. Wait while the shortcut processes the ten artefacts and retrieves additional information from The Metropolitan Museum of Art.
  6. When prompted, choose where you want to save the CSV file.
  7. Save the file to a location you can easily find later, such as Downloads or iCloud Drive.

Make sure you save the CSV file every time you complete the quiz. You will need these files for a later section assignment.

Option 3

Phone or Tablet — Google Chrome or Firefox

If you are using Google Chrome or Firefox on a phone or tablet, use the Anthropeum Exporter bookmarklet instead of the desktop extension.

Show setup and export instructions

One-Time Setup

  1. First, tap Copy Bookmarklet Code above.
  2. Open any webpage in Google Chrome or Firefox.
  3. Save that page as a bookmark.
  4. Open your browser’s bookmarks and edit the bookmark you just created.
  5. Rename the bookmark Anthropeum Exporter.
  6. Delete the existing URL/address in the bookmark.
  7. Paste the bookmarklet code into the bookmark’s URL/address field.
  8. Make sure the pasted code begins with javascript:.
  9. Save the bookmark.

You only need to complete this setup once.

Completing and Exporting the Quiz

  1. Open https://anthropeum.com/ in the same browser.
  2. Complete the quiz and remain on the page showing your results.
  3. Tap the browser’s address bar and begin typing Anthropeum Exporter.
  4. Select the Anthropeum Exporter bookmark when it appears in the suggestions.
  5. A box labeled Anthropeum Mobile Export should appear and begin processing the ten artefacts.
  6. Wait until all objects have been processed.
  7. Tap Download CSV.
  8. Save the CSV file on your device.

Make sure you save the CSV file every time you complete the quiz. You will need these files for a later section assignment.
