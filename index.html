Anthropeum Mobile Export

Use this page to set up the Anthropeum Export bookmarklet on a phone or tablet. You only need to complete the setup once.

Supported browsers
Android: Google Chrome
iPhone/iPad: Safari or Google Chrome

Step 1: Create a bookmark

  1. Open any webpage in your browser, or use the browser's default start page.
  2. Save that page as a bookmark.
  3. Open your browser's Bookmarks and edit the bookmark you just created.
  4. Rename the bookmark Anthropeum Export.
  5. Delete the existing URL/address from the bookmark.

Step 2: Copy the Anthropeum Export code

Tap the button below. The bookmarklet code will be copied to your clipboard.

After copying, return to the bookmark you are editing and paste the code into its URL/address field. Make sure the pasted code begins with javascript:, then save the bookmark.

Copy button not working?

Tap inside the box below, choose Select All, then choose Copy. Paste the entire code into the bookmark URL/address field.

Step 3: Export your Anthropeum results

  1. Open anthropeum.com in the same browser.
  2. Complete the game and remain on the page showing your results.
  3. Tap the browser's address bar and begin typing Anthropeum Export.
  4. Select the Anthropeum Export bookmark when it appears in the suggestions.
  5. Wait while the tool processes the ten artefacts and retrieves The Met metadata.
  6. When processing is complete, tap Download CSV.
  7. Save the CSV file. You will need these files for the later Anthropeum assignment.

Do not refresh or leave the completed results page before exporting. Save a CSV after every assigned Anthropeum game.
